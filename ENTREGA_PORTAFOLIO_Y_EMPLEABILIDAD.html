2. Caso de Estudio Técnico: API RESTful Escalable con Sequelize & JWT

Ficha del Proyecto: Node & Express Web App — Módulos 6, 7 & 8 | Rol: Desarrollador Backend Principal | Stack: Node.js, Express, MySQL 8, Sequelize ORM, JWT, Bcrypt, Multer, Swagger UI | Código: github.com/SebastianSanchez2023/Proyecto-Node-Express-Web-App
1. Breve descripción de la actividad o tarea:

Diseño, implementación y exposición de una API RESTful profesional destinada a la administración de usuarios, perfiles personales, órdenes comerciales y catálogo de productos. El sistema requería una arquitectura modular en capas, persistencia mixta (base de datos relacional MySQL + persistencia de auditoría en archivos planos con `fs`), manejo seguro de carga de archivos binarios vinculados a la base de datos (Multer) y autenticación stateless con JSON Web Tokens (JWT).

2. Desafío principal que implicaba:

Garantizar la consistencia atómica (ACID) en operaciones transaccionales dependientes (creación simultánea de usuario, asignación de perfil 1:1, orden de bienvenida 1:N y vinculación de productos N:M), asegurando que cualquier excepción en la base de datos abortara de manera inmediata todos los cambios (Rollback total) sin retener registros huérfanos. Al mismo tiempo, se requería proteger rutas privadas con JWT sin degradar la latencia ni exponer credenciales sensibles.

3. Solución técnica propuesta:

Se implementó una Arquitectura en Capas (Layered Architecture) separando `routes/`, `controllers/`, `services/`, `middlewares/` y `models/`. La atomicidad se resolvió mediante transacciones controladas de Sequelize (`sequelize.transaction()`) con registro forense de fallos en `logs/transactions_errors.log`. La seguridad se blindó con hooks de hashing automático (Bcrypt), exclusión de contraseñas mediante `defaultScope`, y un middleware `verifyJWT` que valida firmas HS256 y caducidad de tokens. La subida de archivos se estructuró con Multer (`diskStorage`) con nombres únicos anticolisión y actualización automática de los campos `avatar` en MySQL.

4. Herramientas técnicas utilizadas para el desarrollo:

Node.js v18+, Express.js v4.19, MySQL 8.0 con driver `mysql2`, Sequelize ORM v6, `jsonwebtoken`, `bcryptjs`, `multer`, `swagger-ui-express` y `swagger-jsdoc` (OpenAPI 3.0), Postman y Git/GitHub.

5. Principales aprendizajes alcanzados:

Modelado de relaciones complejas en Sequelize (**1:1**, **1:N** y **N:M** con tabla intermedia con atributos extra), optimización de consultas anidadas mediante Eager Loading (`include`) para mitigar el problema *N+1 queries*, diseño de middlewares de autenticación y autorización por roles (RBAC), y estructuración de respuestas HTTP uniformes `{ status, message, data }`.

6. Métricas de impacto logradas:
100% Atomicidad ACID en Transacciones
0% Exposición de Contraseñas (Scopes)
100% Tests Automatizados Aprobados
< 35ms Latencia Media en Consultas
7. Habilidades técnicas y blandas aplicadas:

Hard Skills: Programación asíncrona avanzada (`async/await`, Promises), diseño RESTful, administración de esquemas relacionales, seguridad OWASP, JWT stateless, testing HTTP.
Soft Skills: Resolución metódica de problemas técnicos, pensamiento analítico orientado a datos, autonomía en depuración y comunicación técnica estructurada.

8. Justificación de por qué elegiste este proyecto para formar parte de tu portafolio:

Constituye una muestra concreta de código listo para producción. Resuelve problemas reales que todo desarrollador backend enfrenta en la industria: atomicidad transaccional ante caídas de servicio, seguridad criptográfica en credenciales, integración de binarios en almacenamiento físico con trazabilidad en base de datos y documentación viva estandarizada bajo especificación OpenAPI.
